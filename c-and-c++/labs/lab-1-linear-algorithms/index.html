Упражнение №1. Линейные алгоритмы

Задание 1

Написать программу, вычисляющую значения выражений в соответствии с заданием 1 упражнения по работе с эмулятором процессора.

Задание 2

Написать программу, вычисляющую значения выражения согласно варианта.

Вариант:

  1. \[\sqrt{x}+\frac{\sin{y}}{\ln{z}};\]
  2. \[\sqrt[3]{x}+\frac{\log{}_{10}{y}}{\cos{z}};\]
  3. \[\frac{\mathop{\rm tg}\nolimits{y}}{\sqrt{x}}-\log{}_2{z};\]
  4. \[\sqrt[3]{x}\times\sin{y}-e^{z+1};\]
  5. \[\frac{\sqrt{x}+\cos{y}}{\ln{z}};\]
  6. \[\frac{\sqrt[3]{x}\times\mathop{\rm tg}\nolimits{y}}{\log{}_{10}{z}};\]
  7. \[\frac{\sqrt{x}}{\sin{y}\times e^z};\]
  8. \[\sqrt{x}\times\cos{y}+\log{}_2{z};\]
  9. \[\frac{\sqrt[3]{x}}{\mathop{\rm tg}\nolimits{y}+\log{}_{10}{z}};\]
  10. \[\sqrt{x}+\sin{\frac{y}{\ln{z}}};\]
  11. \[\sqrt[3]{\frac{\cos{x}}{y}}-e^{-z};\]
  12. \[\sqrt{\frac{x}{\mathop{\rm tg}\nolimits{y}+2}}+\log{}_2{\frac{1}{z+1}}.\]

Задание 3

Написать программу, решающую предложенную задачу на движение согласно варианта.

Вариант:

  1. Скорость движения теплохода относительно берега вниз по реке \(v_d\) км/ч, а вверх — \(v_u\) км/ч. Определите скорость течения относительно берега и скорость теплохода относительно воды.
  2. Автоколонна длиной \(s\) м движется со скоростью \(v_c\) км/ч. Мотоциклист выезжает из головы колонны, доезжает до ее хвоста и возвращается обратно. Определите время, за которое мотоциклист преодолеет данное расстояние, если его скорость равна \(v_b\) км/ч.
  3. Пловец, двигаясь относительно воды перпендикулярно течению со скоростью \(v_s\) км/ч, переплывает реку шириной \(w\) м. Скорость течения реки \(v_r\) км/ч. Определите скорость и смещение (в метрках) пловца относительно берега.
  4. Вертолет летел в безветренную погоду на север со скоростью \(v_h\) м/с. С какой скоростью и под каким углом к первоначальному направлению будет лететь вертолет, если подует западный ветер со скоростью \(v_w\) м/с?
  5. На катере необходимо переплыть реку перпендикулярно берега. Какую скорость должен сообщить мотор катеру, чтобы при скорости течения реки, равной \(v_r\) м/с, катер двигался относительно берега со скоростью \(v_b\) м/с?
  6. Пловец желает переплыть реку перпендикулярно берега. Под каким углом к течению он должен плыть, если скорость пловца относительно воды \(v_s\) м/с, скорость течения \(v_r\) м/с?
  7. Скорость течения реки \(v_r\) км/ч, ширина ее \(w\) м. С какой скоростью относительно берега должен плыть пловец, чтобы переплыть реку за \(t\) мин, если его скорость относительно воды перпендикулярна берегу?
  8. По двум взаимно перпендикулярным дорогам движутся равномерно грузовая и легковая машины со скоростями \(v_1\) км/ч и \(v_2\) км/ч соответственно. На каком расстоянии окажутся друг от друга машины через \(t\) мин после встречи у перекрестка?
  9. В безветренную погоду вертолет двигался со скоростью \(v_h\) км/ч точно на север. Найдите скорость вертолета, если подул северо-западный ветер под углом 45° к направлению движения. Скорость ветра \(v_w\) м/с.
  10. Наблюдатель на берегу определил значение скорости пловца, переплывающего реку — \(v_s\) м/с. Скорость была направлена под углом 60° к линии берега. Какова скорость пловца относительно воды, если скорость течения реки \(v_r\) м/с?
  11. По двум пересекающимся под углом 60° дорогам движутся два автомобиля со скоростями \(v_1\) км/ч и \(v_2\) км/ч соответственно. Через какое время после встречи у перекрестка расстояние между ними станет равным \(s\) км?
  12. Пловец, двигаясь относительно воды перпендикулярно течению со скоростью \(v_s\) км/ч, переплывает реку шириной \(w\) м. Скорость течения реки \(v_r\) км/ч. Определите время, которое требуется пловцу, чтобы переплыть реку, и под каким углом к берегу плывет пловец.

Указания

Пример 1

Пример программы, вычисляющей простейшее арифметическое выражение:

#include <cstdio>

int main()
{
    printf("x = ");
    double x;
    scanf_s("%lf", &x);

    printf("y = ");
    double y;
    scanf_s("%lf", &y);

    double z = x * x + y * y;

    printf("%.2lf^2 + %.2lf^2 = %.2lf\n", x, y, z);

    return 0;
}

Пример 2

Пример вычисления выражения \(\sqrt{\sin^n{x}+\cos^k{y}}\)

#include <cstdio>
#include <cmath>

int main()
{
    printf("x = ");
    double x;
    scanf_s("%lf", &x);

    printf("n = ");
    int n;
    scanf_s("%d", &n);

    printf("y = ");
    double y;
    scanf_s("%lf", &y);

    printf("k = ");
    int k;
    scanf_s("%d", &k);

    double z = sqrt(pow(sin(x), n) + pow(cos(y), k));

    printf("sqrt(pow(sin(%.2f), %d) + pow(cos(%.2f), %d)) = %.2f\n", x, n, y, k, z);

    return 0;
}
