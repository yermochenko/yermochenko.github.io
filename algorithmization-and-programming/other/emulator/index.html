Устройство эмулятора

Процессор имеет стек из 8-ми регистров, а также регистр IP (Instruction Pointer), который хранит адрес инструкии, которая должна быть выполнена следующей.

Память состоит из 128 ячеек.

Формат программы:

Первая ячейка памяти (с адресом 0) содержит адрес инструкции, которая должна быть выполнена первой. Между первой ячейкой памяти и ячейкой памяти с первой инструкцией могут быть размещены переменные.

Алгоритм работы процессора:

  1. Процессор копирует значение ячейки памяти с адресом 0 в регистр IP и начинает выполнять инструкции.
  2. Процессор читает ячейку памяти с адресом, равным значению регистра IP. Эта ячейка интерпретируется как код инструкции.
  3. Процессор увеличивает значение регистра IP на число, равное размеру инструкции с прочитанным кодом.
  4. Процессор выполняет инструкцию с прочитанным кодом.
  5. Процессор повторяет пункт 2 до тех пор, пока значение регистра IP не станет равным 0.
